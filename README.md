# Розпізнавання ритмів серця

Навчальний застосунок до курсу «Опрацювання зображень методами штучного інтелекту», варіант 6.
Генерує послідовності значень пульсу для трьох класів — брадикардії, нормального ритму й тахікардії, —
навчає на них просту нейронну мережу (Brain.js) і розпізнає послідовності, введені вручну, завантажені
з файла або отримані наживо з годинника Pixel Watch через Bluetooth.

Це не медичний прилад.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
npm run dev
```

Застосунок відкриється на http://localhost:5173. Для підключення годинника потрібен Chrome або Edge:
інші браузери не підтримують Web Bluetooth.

| Команда           | Що робить                                         |
| ----------------- | ------------------------------------------------- |
| `npm run dev`     | сервер розробки                                   |
| `npm run build`   | перевірка типів і збирання в `dist/`              |
| `npm run preview` | перегляд зібраної версії на http://localhost:4173 |
| `npm test`        | модульні тести (Vitest)                           |

## Як користуватися

1. **Дані.** Виберіть профілі набору, кількість послідовностей на клас, допуск і seed, натисніть
   «Згенерувати набір». Набір можна зберегти у CSV чи JSON або завантажити власний.
2. **Навчання.** Задайте кількість епох, швидкість навчання та інші параметри, натисніть «Навчити мережу».
   Смуга прогресу внизу рухається за епохами; навчання можна зупинити. Модель зберігається у JSON.
3. **Розпізнавання.** Введіть чотири числа або серію довільної довжини й натисніть «Розпізнати».
   Довга серія ділиться на вікна по чотири числа, відповіді мережі усереднюються.
   Зображення результату зберігається у PNG, JPG або BMP.
4. **Годинник.** Пульс наживо з Pixel Watch або із симулятора; мережа оцінює ритм за останніми
   чотирма значеннями.

Нижня панель на всіх вкладках показує поточну операцію, її хід, час виконання й лог, який можна зберегти у файл.

## Підключення Pixel Watch

1. На годиннику проведіть униз від циферблата, відкрийте **Connected Fitness** і натисніть **Connect**.
   Першого разу ввімкніть **Wider device access**.
2. У застосунку відкрийте вкладку «Годинник», виберіть «Pixel Watch (Bluetooth)» і натисніть «Підключити».
3. У вікні браузера виберіть годинник і підтвердьте пристрій на годиннику. Якщо Windows покаже сповіщення
   про створення пари або попросить PIN, погодьтеся.

Екран Connected Fitness має лишатися відкритим, доки триває підключення. Поки з’єднання не підтверджено,
годинник розриває зв’язок, тому застосунок сам повторює спробу до шести разів. Якщо не допомогло:
перезапустіть Connected Fitness на годиннику, вилучіть годинник зі списку пристроїв Bluetooth у Windows
(якщо він там є) і спробуйте ще раз.

Годинник передає пульс за стандартним профілем Bluetooth Heart Rate, тому так само підключається
будь-який нагрудний пульсометр. Сторінка має бути відкрита з `localhost` або через HTTPS —
інакше браузер не дозволить Bluetooth.

## Будова коду

```
src/
  domain/   класи ритму, генератор послідовностей, нормалізація, ковзне вікно, метрики, файли набору
  ml/       обгортка над Brain.js, робочий потік (Web Worker) для навчання й перевірки
  watch/    джерела пульсу: Bluetooth і симулятор
  export/   збереження файлів, кодувальник BMP, перетворення графіків на зображення
  log/      лог операцій
  state/    стан застосунку
  ui/       вкладки, графіки, спільні компоненти
```

Навчання й перевірка виконуються у Web Worker, тому інтерфейс не завмирає, а навчання можна зупинити.
Генератор використовує власний генератор випадкових чисел із seed: однакові параметри дають однаковий набір.
